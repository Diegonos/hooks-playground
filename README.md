# React Hooks Playground

A small React playground project built to experiment with and better understand React Hooks.

This project is focused on:

- Custom hooks
- State management with hooks
- Effects and lifecycle behavior
- Re-renders and memoization
- Hook composition
- React hook patterns and best practices

Tech stack:

- React
- TypeScript
- Vite
- ESLint
- Prettier

The goal of this repository is purely educational and experimental.
